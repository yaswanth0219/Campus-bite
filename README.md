# CampusBite

A polished front-end MVP for the CampusBite university food pre-ordering concept.

## Run it

Open `index.html` directly in a browser, or use VS Code Live Server.

## Current demo

- Responsive student-facing UI
- Food court menu with categories
- Add/remove cart items
- Persistent cart using localStorage
- Pre-order confirmation with unique pickup code
- Pay-at-pickup messaging
- Vendor dashboard demo interaction

## Next build step

- student authentication
